# 从零开始装好 Amane（傻瓜版）

> 这份文档假设你**什么都不知道**。每一步都写了三件事：**你要做什么 → 看到什么算成功 → 不对怎么办**。
> 卡住时先看对应那一步的「不对怎么办」，90% 的问题都在那几行里。

先花 30 秒确认你属于哪种情况：

| 你的情况 | 走哪条路 |
|---|---|
| 已经有人帮你搭好了服务（比如家里 NAS 上跑着 Amane），你只要装手机 App | 跳到 [第 3 步](#3-装-app几分钟不用装开发工具) |
| 你有一台 NAS 或一台常开的电脑，想从零搭 | 从 [第 1 步](#1-准备先看一眼这些有没有) 开始 |
| 两样都不是，也没耐心折腾 | 看 [第 0 步](#0-找个会的人-30-秒版) |

---

## 0. 找个会的人（30 秒版）

把下面这段整段发给会用电脑的朋友，或者你自己的 AI 助手：

```text
帮我在这台机器上部署 Amane-Harmony 的旁挂服务，按
https://github.com/dogmicats/Amane-Harmony/blob/main/docs/START.md 做。
机器必须已经在跑 Amane（能读到 amane 的 data 目录），不是你的沙箱。
做完把「用户服务地址」和「API token」告诉我，我要填进手机 App。
```

**你要自己做的**只有两件事：给 token（不要让他在聊天里打出来，让他写在你机器上的 `.env` 里）、拿到两个地址。

---

## 1. 准备（先看一眼这些有没有）

| 需要 | 说明 |
|---|---|
| 一台电脑 | Windows / macOS 都行；只在「签名 + 推包」这一刻用 |
| Docker | NAS 用户在「套件中心」装容器套件即可；电脑上装 Docker Desktop |
| 一个华为账号 | 免费注册。**必须**——没有它签不出能装进你手机的包 |
| 你的手机 | 鸿蒙系统（HarmonyOS NEXT） |

数据线**不是必须的**：现在的侧载工具（Hokit、小白调试助手等）支持同一 WiFi 下无线连接，插不插线都行。

⏱ 全程约 15–30 分钟，装 App 那一步现在只要几分钟。

**先理解一件事**：鸿蒙手机不允许装「没有签名」的安装包，也不存在能给别人用的通用签名——**每个人要用自己的账号给自己的手机签一次**。好在这件事侧载工具会替你做，你只需要在工具里登录一次华为账号。

---

## 2. 装服务（约 10 分钟）

> 已经有别人帮你搭好服务的，跳过这一步。

**2.1 下载仓库**

打开 <https://github.com/dogmicats/Amane-Harmony>，点绿色 `Code` → `Download ZIP`，解压到一个你能找到的目录（比如 `D:\Amane-Harmony`）。

**2.2 填两个值**

进 `deploy` 目录，把 `.env.example` 复制一份改名成 `.env`，用记事本打开，改这两行：

```ini
AMANE_DATA=/换成/你/amane/的/data/目录
AMANE_TOKEN=换成你的-token
```

- `AMANE_DATA`：Amane 的 data 目录，里面应该有 `amane.db` 这个文件。找不到就问一下当初帮你装 Amane 的人。
- `AMANE_TOKEN`：那个目录里有个叫 `token` 的文件，用记事本打开，把里面的内容整段复制过来。

**2.3 启动**

在仓库根目录打开终端（Windows 在文件夹地址栏输入 `powershell` 回车也行），执行：

```bash
docker compose -f deploy/compose.example.yml up -d
```

第一次会下载几百兆，等它跑完。

**2.4 看到什么算成功**

浏览器打开 `http://你机器的地址:8770/api/user/ping`，看到类似这样就是成功：

```json
{"ok": true, "version": "2.5.0", "time": "..."}
```

**不对怎么办**

| 现象 | 怎么办 |
|---|---|
| 打不开、连接被拒 | 服务没起来：`docker compose -f deploy/compose.example.yml logs --tail 30` 看最后的红字 |
| 返回 `{"detail": "缺少或无效的 token"}` | 这一步正常 —— 你还没带 token。说明服务活着，继续往下走 |
| 提示读不到 `amane.db` | `AMANE_DATA` 填错了，回到 2.2 检查路径 |

---

## 3. 装 App（几分钟，不用装开发工具）

> 这一步要做的是「给自己手机签个名再装进去」。现在的侧载工具已经把这件事包好了，
> **不需要装 DevEco、也不需要数据线**。只在换手机或证书过期时再做一次。

**3.1 先把包下载下来**

打开 <https://github.com/dogmicats/Amane-Harmony/releases>，选最新的那个版本，
下载 `Amane-<版本号>-unsigned.hap`（**unsigned 是对的**，工具会帮你签）。

**3.2 装一个侧载工具**

[**Hokit**](https://hokit.dev) 或 **小白调试助手** 之类，能在电脑上「本地签名 + 推包安装」的都行。
从它们的官网 / 官方渠道下载——**别用来路不明的安装包**。

**3.3 手机准备（一次性）**

设置 → 关于本机 → 连点「版本号」7 次 → 回设置 → 系统 → 开发者选项 →
打开「USB 调试」和「无线调试」。

**3.4 连设备**

- **无线**：手机和电脑连同一个 WiFi，打开工具里的「无线连接 / 扫码配对」，按工具提示输配对码
- **有线**：插上数据线，手机弹「是否允许调试」→ 允许

**3.5 签名并安装**

在工具里选刚下载的 `.hap` → 它会用你的华为账号做本地调试签名 → 安装。
第一次会让你登录华为账号，登一次就行（这就是「给自己手机签名」那一步）。

装完桌面就有 Amane 了。

**3.6 如果工具说「只接受已签名包」**

少数工具不做本地签名。那就用 DevEco 这条路（装一次，以后不用再装）：

1. 装 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)，首次启动登录华为账号
2. `File → Open` 打开解压出来的 **`app`** 目录（不是仓库根目录），等右下角同步跑完
3. `File → Project Structure → Signing Configs`，勾上 **Automatically generate signature**
4. 手机连上（有线或无线都行），顶部选到设备，点绿色 ▶

**不对怎么办**

| 现象 | 怎么办 |
|---|---|
| 工具连不上手机 | 确认手机和电脑在**同一个 WiFi**、开发者选项里「无线调试」是开的；有线则检查「是否允许调试」有没有点允许 |
| 报「未签名 / 签名不匹配」 | 这个工具不做本地签名，走 3.6 |
| 装到一半失败 | 手机上可能已有同包名的旧版：先在设置里卸载旧的，再装 |
| DevEco 里运行按钮是灰的 | 设备下拉框没选中手机，重插线或重连无线，确认手机上点了「允许」 |

---

## 4. 让 App 连上你的库（2 分钟）

**4.1** 打开 App → 右下角「我的」→「设置」→「连接」

**4.2** 填两个地址（手机和机器要在同一个 WiFi 下）：

| 填什么 | 怎么填 |
|---|---|
| amane 地址（媒体与播放） | `http://你的机器IP:8000` |
| 用户数据服务地址 | `http://你的机器IP:8770` |
| API Token | 第 2.2 步那个 token |

IP 不知道：Windows 上开 `cmd` 输 `ipconfig`，看「IPv4 地址」，形如 `192.168.3.103`。

**4.3** 点「测试连接」，看到版本号就通了；再点「保存并重连」。

**不对怎么办**：先用**手机浏览器**打开 `http://你的机器IP:8770/api/user/ping`。
- 浏览器也打不开 → 是网络/防火墙，不是 App 的问题（关掉电脑防火墙再试）
- 浏览器能开、App 连不上 → 地址少写了 `http://` 或端口写错了

---

## 5. 装好了，先玩这三下

很多功能用文字说不清，**上手点两下就懂了**。30 秒：

1. **媒体库 → 点「抽卡」** —— 整屏随机剧照，看上哪张点哪张
2. **随便点开一部片 → 看「亮点」** —— 6 张带时间点的画面，点哪张从哪秒开始播
3. **搜索框输 `ntr`** —— 拼音、俗称都能搜到库里的正片

## 6. 以后怎么更新

更新分两块，**能自动的程度差很多**，先记住这一句：

> **服务端可以交给 AI 助手升完；手机 App 只能升到「存进手机」为止。**

**① 服务端（第 2 步那个容器）—— 这块真能一句话搞定**

有新版本时客户端会提示。最省事的办法是把下面这段发给你的 AI 助手，它会在你那台机器上做完备份、拉代码、重建、验证：

```text
请按 https://github.com/dogmicats/Amane-Harmony/blob/main/docs/UPGRADE.md 帮我把 amane-user 升级到最新版。
先判断 compose 里是 build: 还是 image:，再备份 data/，然后 git pull 加 docker compose up -d --build；
完成后轮询 /api/user/ping 把 version 报给我。任何一步失败就停下报告，不要动 data/ 里的文件。
```

升级完回 App 点一次「重新检查」，服务端那行会变成新版本号。

**② 手机 App —— 我只负责把包送到你手上**

我的 → 设置 → 检查更新 → 点那个大按钮，它会下载、校验、存到手机。

然后**要你自己装**：存下来的是未签名包，跟第一次装一样得用你自己的证书签一次。
不是偷懒 —— 鸿蒙不允许 App 自己装自己，侧载工具也不提供能让程序调用的安装接口，
这一步只能人动手：

- 用侧载工具：把手机里那个 `.hap` 传到电脑（或工具支持直接选手机上的文件），走一次第 3.5 步
- 用 DevEco：把文件替换进项目重新运行一次

先用着也完全没问题 —— App 会一直提示有新版本，等你方便的时候再装。

## 7. 一页纸排错

| 你看到的 | 真正的原因 |
|---|---|
| App 一直「读取媒体库…」转圈 | 服务端没起，或 App 里地址填错（第 4 步） |
| 列表能刷出来，但海报是空白方块 | 图片代理没通：确认「用户数据服务地址」填的是 `:8770` 那个，不是 `:8000` |
| 点播放一直转 | 服务端读不到影片文件：`MEDIA_PATH_MAP` 路径映射没配（问帮你搭的人） |
| 收藏 / 历史一点就空 | 同上，或 token 填错 |
| 手机换了个 App 版本，收藏没了 | 收藏存在服务端 `data/user.db`，不在手机里；检查是不是连到了另一个实例 |

还是不行：把「我的 → 设置 → 高级 → 导出运行日志」存下来的 txt 发给会看的人，那是定位问题最快的材料。
